## 2026-06-25 - Prevent concurrent provider download race conditions
**Learning:** Using Terraform's plugin cache (`TF_PLUGIN_CACHE_DIR`) with concurrent downloads (like `terragrunt run-all`) leads to race conditions and corrupt installations in CI.
**Action:** Use Terragrunt's native provider caching (`TERRAGRUNT_PROVIDER_CACHE=1`) instead to safely handle concurrent provider downloads and improve speed.
