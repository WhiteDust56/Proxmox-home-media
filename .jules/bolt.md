## 2024-10-24 - Optimize Provider Caching in GitHub Actions
**Learning:** Terragrunt's native provider caching (`TERRAGRUNT_PROVIDER_CACHE=1`) is significantly more robust and prevents redundant downloads compared to Terraform's `TF_PLUGIN_CACHE_DIR`, especially when dealing with concurrent provider downloads across multiple root modules. Also, GitHub Actions `env` variables do not automatically resolve shell variables like `$HOME`, which can lead to mismatching paths and empty caches.
**Action:** Always use Terragrunt's native provider cache (`TERRAGRUNT_PROVIDER_CACHE=1`) when using Terragrunt, and explicitly use `${{ github.workspace }}` for both `TERRAGRUNT_PROVIDER_CACHE_DIR` and the `actions/cache` path to ensure they resolve to the exact same absolute directory.
