## 2024-06-26 - Terragrunt Provider Caching
**Learning:** Using Terraform's native `TF_PLUGIN_CACHE_DIR` with `terragrunt run-all` causes redundant downloads and race conditions during concurrent initialization. Terragrunt's native cache (`TERRAGRUNT_PROVIDER_CACHE=1`) safely handles concurrent provider downloads.
**Action:** Always use Terragrunt's native provider cache (`TERRAGRUNT_PROVIDER_CACHE=1` and `TERRAGRUNT_PROVIDER_CACHE_DIR`) in CI/CD pipelines when running concurrent Terragrunt operations, and set the cache directory to a workspace-local path like `.cache/terragrunt/providers` to ensure GitHub Actions correctly resolves the path.
