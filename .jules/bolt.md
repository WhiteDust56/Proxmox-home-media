## 2026-06-12 - Terragrunt CI Provider Caching
**Learning:** Using Terraform's plugin cache (`TF_PLUGIN_CACHE_DIR`) with Terragrunt concurrent operations (`run-all`) can cause race conditions, corrupt downloads, and is generally slower.
**Action:** Use Terragrunt's native provider caching (`TERRAGRUNT_PROVIDER_CACHE=1` and `TERRAGRUNT_PROVIDER_CACHE_DIR`) instead of `TF_PLUGIN_CACHE_DIR` to optimize concurrent CI operations.
